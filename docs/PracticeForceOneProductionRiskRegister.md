### R15 one-paster — ✅ EXECUTED 2026-07-11 by AgentMR8 (kept for reference/rebuild; verified post-create: bucket ACTIVE/2200d, sink filter correct, same-project destination so no extra IAM)

```
gcloud logging buckets create audit-fallback --location=global --retention-days=2200 --description="AUDIT-FALLBACK long retention (HIPAA 6-year)" --project=claimsprocessing
gcloud logging sinks create audit-fallback-sink logging.googleapis.com/projects/claimsprocessing/locations/global/buckets/audit-fallback --log-filter="resource.type=\"cloud_run_revision\" AND textPayload:\"[AUDIT-FALLBACK]\"" --project=claimsprocessing
```

This copies every future `[AUDIT-FALLBACK]` line into a dedicated log bucket retained ~6 years (2200 days); the default `_Default` bucket is unchanged. **Note:** fallback events older than 30 days are already gone from Cloud Logging — the sink protects from the day it's created, which is a reason to run it promptly.
